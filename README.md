# 文字数カウントくん

ブラウザ完結型で、テキスト全体の文字数と選択範囲の文字数をリアルタイムでカウントできるシンプルで便利なツールです。

## 主な機能

- **リアルタイム文字数カウント**: 入力・選択に合わせて全体および選択範囲の文字数を即座に表示。
- **サロゲートペア対応**: 絵文字や特殊文字も正確にカウント。
- **空白除外オプション**: スペースやタブを除外した文字数の計測に対応。
- **クイック操作**: クリップボードからの貼り付けや一括クリアボタンを搭載。

## 使用技術

- **Frontend**: Vue 3 (Composition API / `<script setup>`)
- **Runtime**: Deno
- **Build Tool**: Vite
- **Language**: JavaScript (ES Modules)
